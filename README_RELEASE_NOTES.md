# CHRONO / 03 BIO v1.2.0

## English

The first packaged release of the BIO clock, using the latest corrected digit geometry.

- Symmetric SVG segments with a shared rightward slant and clean joints.
- White mecha case with frosted electronics, optical lenses, speakers and preserved-moss artwork.
- English/Russian UI and visual editor; automatic language selection from HA.
- Optional seconds, configurable time zone/date locale, brightness and night dimming.
- Single-file distribution with embedded artwork and a standalone bilingual preview.

Local automated checks pass. Live Home Assistant installation testing remains pending. Catalog inclusion is separate from installing this as a HACS custom repository.

## Русский

Первый оформленный релиз BIO-часов с последней исправленной геометрией цифр.

- Симметричные SVG-сегменты, единый наклон вправо и ровные стыки.
- Белый меха-корпус с матовыми панелями, электроникой, оптикой, динамиками и мхом.
- Русский и английский интерфейс и редактор; автоматический язык по настройкам HA.
- Отключаемые секунды, часовой пояс, язык даты, яркость и ночной режим.
- Один JS-файл со встроенной графикой и самостоятельный двуязычный предпросмотр.

Локальные автоматические проверки пройдены. Установка на живом Home Assistant пока не проверена. Включение в общий каталог и установка как пользовательского HACS-репозитория — отдельные этапы.
